# Confere Aí – Projeto Integrador

Produção técnica da disciplina Design Profissional (UNIPÊ): diagramas do aplicativo Confere Aí, que ajuda idosos a verificar se um telefone, site ou empresa já foi denunciado como golpe.

## Principais funcionalidades
- Pesquisar uma empresa e ver se tem denúncias de golpe
- Pesquisar um número de telefone denunciado
- Registrar uma denúncia de golpe
- Verificar se um link ou site já foi denunciado
- Guia passo a passo do que fazer ao suspeitar de golpe
- Verificação automática de ligações recebidas (versão futura)
